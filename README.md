# SYNTŌPOLIS — Digital Island

**Version 0.1**

SYNTŌPOLIS is a digital laboratory for modelling a cooperative society on a living island.

The first version is deliberately concrete:

- a 2 × 2 km island;
- one central settlement;
- 100 simulated residents;
- basic systems for water, energy, food, housing, work and education;
- first-person entry into the world;
- a social-state dashboard.

## Project status

The project is in **pre-production / foundation**. The canon, world model, social simulation and Unreal Engine architecture are being defined before full production begins.

## Repository map

- `00_CANON/` — approved concept and immutable foundations
- `01_WORLD/` — island, landscape, climate and nature
- `02_SETTLEMENT/` — spatial plan, architecture and infrastructure
- `03_SOCIETY/` — residents, roles, needs and relationships
- `04_SYSTEMS/` — water, energy, food, housing, work and education
- `05_SIMULATION/` — rules, metrics, time and social dynamics
- `06_UNREAL/` — Unreal Engine project architecture and implementation notes
- `07_UI/` — first-person interaction and society dashboard
- `08_ROADMAP/` — milestones and production sequence
- `09_RESEARCH/` — references, experiments and open questions

## Canonical rule

Documents in `00_CANON` describe the approved foundation. Changes to canon must be explicit and recorded. Ideas under development belong in the other sections until approved.
