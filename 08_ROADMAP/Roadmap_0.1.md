# Roadmap — SYNTŌPOLIS 0.1

## Phase 0 — Foundation

- approve the canonical concept;
- define repository and Unreal architecture;
- establish naming and documentation rules;
- select Unreal Engine version and target platform.

**Exit:** concept, scope and technical direction are stable.

## Phase 1 — The Living Island

- design island geography;
- produce 2 × 2 km heightmap;
- create coastline, water and terrain materials;
- add basic vegetation and climate;
- choose central settlement site;
- implement first-person exploration.

**Exit:** the whole island is navigable and spatially convincing.

## Phase 2 — The Settlement

- block out the central settlement;
- place housing for 100 residents;
- add communal, educational and work spaces;
- represent water, energy and food infrastructure;
- establish walking routes and functional zones.

**Exit:** the settlement reads as a plausible complete community.

## Phase 3 — One Hundred Residents

- implement resident and household schemas;
- create demographic and competency distribution;
- add needs and daily routines;
- simulate all residents in data;
- visualize nearby residents in the world.

**Exit:** 100 persistent residents live through an accelerated day.

## Phase 4 — Essential Systems

- connect water, energy, food, housing, work and education;
- implement production, storage and consumption;
- model dependencies and shortages;
- expose state through buildings and resident behaviour.

**Exit:** every essential system can function, degrade and recover.

## Phase 5 — Society Dashboard

- show population and system indicators;
- connect aggregate metrics to individual residents;
- add time controls;
- add explanations for changes;
- implement a small set of test scenarios.

**Exit:** the user can understand what is happening and why.

## Phase 6 — Integrated Prototype

- save and load;
- performance pass;
- audio and atmosphere;
- onboarding route;
- stability testing;
- package a distributable build.

**Exit:** an external user can enter, explore and understand SYNTŌPOLIS 0.1 without developer assistance.

## Immediate next task

Create and approve the island design brief: silhouette, terrain zones, settlement position, freshwater logic, climate and visual references.
